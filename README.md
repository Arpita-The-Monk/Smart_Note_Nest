# Smart Note Nest

## Project Description

Smart Note Nest is a simple web-based note management application for students.
It allows users to create, edit, delete, search, and organize their notes easily.

## Features

- Create new notes
- Edit existing notes
- Delete notes
- View complete note details
- Mark notes as favorites
- Search notes
- Filter notes by category
- View notes by category
- Dark mode
- Responsive design for smaller screens
- Save notes using browser localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage

## How It Works

HTML is used to create the basic structure of the application, such as the navigation bar, buttons, forms, cards, and different sections.

CSS is used to design the application. It controls colors, fonts, spacing, layout, buttons, cards, and responsive design.

JavaScript is used to add dynamic functionality such as creating, editing, deleting, searching, and favoriting notes.

Browser localStorage is used to store note data. This allows the notes to remain available even after refreshing the browser.

## Main Pages

### Home
Shows an overview of the total notes, favorites, and categories.

### Create Note
Allows users to create a new note by entering a title, category, and content.

### My Notes
Shows all saved notes and provides search, category filtering, view, edit, and delete options.

### Categories
Organizes notes into different categories such as Study, Personal, Ideas, Projects, and Others.

### Favorites
Shows all notes marked as favorites.

### Note Details
Shows the complete information of a selected note.

## Future Improvements

In the future, the application can be improved by adding a cloud database, user login, note synchronization, and AI-based assistance.

## Project Goal

The main goal of Smart Note Nest is to provide students with a simple and organized platform for managing their personal study notes.
